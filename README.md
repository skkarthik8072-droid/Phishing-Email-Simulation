# Phishing Email Simulation

## Project Overview
Phishing Email Simulation is a Cyber Security Awareness Training project developed using Python and Streamlit. It helps users learn how to identify phishing emails and legitimate emails through educational sample scenarios.

## Objectives
- Understand common phishing email patterns.
- Identify suspicious messages and email requests.
- Evaluate user awareness through sample email questions.
- Display results and awareness scores using a dashboard.

## Technologies Used
- Python
- Streamlit
- SQLite Database

## Features
- Participant registration
- Sample phishing and legitimate emails
- Interactive answer selection
- Automatic answer checking
- Response storage using SQLite
- Awareness score and result dashboard
- Security recommendations

## Installation
1. Install Python on your computer.
2. Open the project folder in the terminal.
3. Install the required package:

   `pip install -r requirements.txt`

4. Run the application:

   `python -m streamlit run app.py`

5. Open the local URL shown in the terminal.

## Educational Use
This project is intended for cybersecurity awareness and educational testing. It uses sample emails and does not require real passwords or OTPs.
